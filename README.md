## The notebooks

Click **Open in Colab**: the notebook opens in your browser, with nothing to install (a Google account is needed to run it).
Fill in every `____` and every `# YOUR CODE HERE`, and run the cells top to bottom. Each exercise ends with a checkpoint
that tells you whether you got it right. Tiers: ★ Core (everyone), ★★ Stretch, ★★★ Challenge.

To work locally instead: Python 3 with numpy, pandas, scipy, scikit-learn and matplotlib.
